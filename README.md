# 💄 Glamora Makeup

Glamora Makeup is a modern, premium beauty and cosmetics website designed to provide an elegant and responsive shopping experience across desktop, tablet, and mobile devices.

## ✨ Features

- Promotional announcement bar for shipping and first-order offers
- Responsive header and navigation
- Glamora branding and logo presentation
- Hero section with new collection messaging
- High-performance makeup messaging
- Shop Now and Explore Collection buttons
- Makeup product and category sections
- Mobile-friendly category slider
- Existing makeup imagery and interface icons
- Feature tabs for:
  - Free Shipping
  - Clean & Safe Products
  - Secure Payment
  - Easy Returns
- Newsletter subscription section: “Beauty in Your Inbox”
- Contact page with support information and contact form
- FAQ section
- Footer with shopping, customer care, and brand links
- Payment method section
- Responsive mobile layout

## 🛠️ Tech Stack

- **HTML5**  
  Used to structure the website content, sections, navigation, product areas, contact page, and footer.

- **CSS3**  
  Used for styling, responsive layouts, typography, colors, spacing, product presentation, and mobile adaptations.

- **JavaScript**  
  Included as part of the frontend technology stack for supporting interactive website behavior where applicable.

## 📱 Responsive Design

Glamora Makeup is designed to adapt across different screen sizes:

- **Desktop:** Full navigation, spacious product layouts, feature tabs, and multi-column footer sections.
- **Tablet:** Flexible content arrangements with adjusted spacing and sizing.
- **Mobile:** Compact navigation, responsive typography, stacked content sections, and horizontally scrollable category areas.

## 🎨 Design

The website follows a premium and elegant beauty-inspired visual direction, including:

- Premium cosmetics aesthetic
- Soft pastel colors with refined accent tones
- Clean and readable typography
- Modern spacing and balanced layouts
- Responsive design patterns
- Product-focused visual presentation
- Smooth interactions and animations where applicable

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder in your code editor.
3. Open `index.html` directly in a web browser.

For a better development experience in Visual Studio Code:

1. Install the **Live Server** extension.
2. Right-click `index.html`.
3. Select **Open with Live Server**.
4. The website will open in your default browser.

## 💻 How to Use

- Browse the homepage hero section and featured collection content.
- Use the navigation menu to explore different website sections.
- Browse makeup categories and product imagery.
- Use the Shop Now and Explore Collection buttons to access shopping areas.
- Scroll horizontally through categories on mobile devices.
- Subscribe through the “Beauty in Your Inbox” newsletter section.
- Visit the contact page to view support information, submit a message, review FAQs, or view the office location.
